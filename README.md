One original dad joke, written for make.fun's "Dad Joke Showdown" bounty. A father answers his son with a pun that lands on the first read and needs no explaining.

## The joke

> My son said my jokes aren't funny. I said, 'They're not meant to be funny — they're groan-up jokes.'

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

That writes the joke (100 characters, inside the 200-character gate) to `/tmp/out/entry.txt`.
